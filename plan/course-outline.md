# Course Title: 2026 Mayo Clinic Platform Surgical Innovation Challenge (3 days)

## Course Description

Surgical innovation with AI and clinical data requires secure access to de-identified healthcare datasets, clear export governance, and collaborative cloud computing environments. Navigating these requirements while rapidly prototyping clinical solutions during a multi-day hackathon requires structured coordination and clear workspace boundaries.

This three-day hackathon brings together developers, researchers, and clinical experts to build AI solutions using the Mayo Clinic Platform and Google Cloud tools. Participants receive access to de-identified surgical datasets, virtual machines, and accounts to experiment across five build sprints, culminating in final demonstrations and awards.

## Learning Objectives

- Prototype and present an AI-driven surgical innovation solution using Mayo Clinic Platform data and Google Cloud tools
- Navigate the event schedule, workspace rules, de-identified datasets, and build sprint milestones from kickoff to final presentations

## Who Should Attend

Data Scientists, AI and ML engineers, and Healthcare Researchers.

## Prerequisites

- Familiarity with data analysis, machine learning, AI, and software development

## Hands-On Activities

- None (Open Hackathon Build Sprints)
